# 中华美食地图

一个零依赖的“小程序式”网页 Demo：用户点击中国任一省级地区后，页面会按市/区展示当地完整美食清单、热度标签和收藏入口。页面支持中文/English 切换，方便本国和外国用户使用。

## 功能

- 覆盖中国 34 个省级行政区：23 个省、5 个自治区、4 个直辖市、香港、澳门、台湾。
- 基于 `区县精准特色美食大全.docx` 整理，覆盖 34 个省级行政区、155 个市/区点位、484 道美食。
- 每道美食都精确到所在市、区、州或地区；详情页按市/区分组展示当前地区的全部推荐菜品。
- 支持按大区筛选：华北、东北、华东、华中、华南、西南、西北、港澳台。
- 支持地区榜单：按热度展示 TOP 3 和全量地区排行，点击榜单项回到该地区美食推荐。
- 支持中文、英文搜索地区、美食、城市、标签和推荐文案；已处理中文输入法拼写合成状态。
- 支持中文/English 一键切换，地区、城市、菜名、标签和核心界面文案均双语展示。
- 支持收藏菜品，收藏数据保存在本机浏览器 `localStorage`。
- 可作为 Figma demo 参考稿，入口为 `figma-import.html`。

## 推荐口径

推荐内容按用户提供文档整理，并结合“本地代表性、游客打卡热度、短视频传播画面感、真实消费场景”的方式展示。当前 Demo 使用静态样例数据，不接入抖音实时接口，也不声明为抖音官方榜单。

## 数据导入

`scripts/import_food_doc.py` 会读取用户提供的 Word 文档，生成 `src/food-data.js`。文档末尾的追问和 AI 注释不会作为程序指令执行，只作为非数据内容忽略。

## Run

```bash
npm run dev
```

或直接运行：

```bash
node server.mjs
```

Build for production:

```bash
npm run build
```
